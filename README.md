# medical-device-kg-pipeline
Ontology-first RDF rebuild pipeline for the FRINK-published medical-device-kg: IRI minters (iri.py), literals/provenance (common.py), UDI/AccessGUDID ingest, recall distribution parser, SHACL shapes, and the bmedesign.org namespace migration. NSF Proto-OKN subaward 5136002; NIH R25EB035522.
