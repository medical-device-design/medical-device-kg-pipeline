# Live okn.us graph vs the rebuild, class by class (10 October 2026)

**Live graph:** `http://medicaldevice.com/ontology/` namespace, 17,862,535 triples, counts from the published class inventory.

**Rebuild:** `https://bmedesign.org/medical-device-kg/` namespace, built on the build VM into `work/out-2026-10-09/`. Every file passed riot, and SHACL where shapes exist. Counts come from a census of the `a <Class>` lines in every file. Classes shared across files (product codes, manufacturers, recalls, recall events and so on) are counted once per distinct IRI.

**Nothing has been published.** The rebuild replaces the live graph only after the PI's decision and the lakeFS staging steps.

## Where the rebuild has less

Each of these is deliberate, and each is reversible:

1. **CFR scope.** Parts 800–898 and 1000–1050 only (2,601 sections against 2,842). If the other parts are wanted, it is one argument in `cfr.py`.
2. **TPLCRecord.** No empty aggregates for product codes that have never had a MAUDE report.
3. **Manufacturer.** Fewer nodes because name variants are not minted as separate manufacturers. The names are kept on FirmName and the identity mappings.
4. **Contact persons** are never ingested, from any source: 522 pages, IVD detail pages, recall contacts, 510(k) contacts, registration correspondents and US agents, and UDI customer contacts.
