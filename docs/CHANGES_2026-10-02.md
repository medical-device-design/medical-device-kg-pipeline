# Changes, 2 October 2026: identity backbone, licence gate, recall database

These changes implement the first graph-track tasks of the Analysis folder's three-year plan: A1 (identity backbone) and A2 (licence register). They also add the recall database as a source. Every module self-tests, and the new recall source was checked on 1,000 live openFDA records.

## What was added or changed

| File | What it does |
|---|---|
| `licence_register.csv` (repo root) | One row per source: licence, URL, `open_release` yes/no. **A2 gate.** |
| `pipeline/licence.py` | Loads and validates the register. `check()` refuses a source with no row, and refuses licensed sources unless built into `--restricted-out`. |
| `pipeline/run.py` | Calls the licence gate before every source. A source with no row is BLOCKED and counts as a failure. New `--restricted-out` flag for licensed overlays. |
| `pipeline/identity.py` | **A1 backbone.** Normalizes organization names. Links FirmName nodes to FEI- or DUNS-keyed nodes as reified `ex:IdentityMapping` blocks (method, confidence, status, date, evidence). Shared identifier = 1.0. Exact normalized name = 0.95. Token score is penalized by extra distinguishing words. **Never `owl:sameAs`.** The measured false positive ("Apple Inc." vs "Apple Diagnostic Products") scores 0.6, so it is a *candidate* for human review, not accepted. |
| `pipeline/sources/recall_db.py` | **New source:** openFDA `device/recall` (59,330 records on 2026-10-02, vs about 40K in `device/enforcement`). It adds the **firm FEI** (an exact identity join to establishments), the **FDA root cause**, termination and posting dates, the firm's action, and recall **events**. It writes to the same `iri.recall()` node as `recalls.py`, so the two sources enrich one record. |
| `pipeline/sources/recalls.py` | `ex:status` changed to `ex:recallStatus` (the ontology term). Adds classification and termination dates, a recall-event link, a firm-name node, and structured geography. |
| `pipeline/distribution_parser.py` | See the list below. |
| `pipeline/iri.py` | New minters: `recall_event`, `firm_name`, `identity_mapping`. The self-test now pins 30 minters. |
| `ontology/ontology.ttl` | New terms: `ex:Mapping` (superclass; NAICS mapping is now a subclass), `ex:IdentityMapping`, `ex:FirmName`, `ex:RecallEvent`, the identity properties, the recall lifecycle properties, and the geography properties. Mapping property domains widened to `ex:Mapping`. |
| `ontology/shapes/identity.shacl.ttl` | Shapes for the new classes. **Fails the release if any `owl:sameAs` appears.** Requires `distributedToState` to be a 2-letter code. |
| `docs/STRUCTURE_COMPLETION.md` | **A real lakeFS secret key was in this file. It is redacted. Ask Yaphet to rotate the key.** |

### Distribution parser changes

- Reads full state names. The recall database writes "Vermont" where the enforcement feed writes "VT".
- Reads unlabeled phrasings: "United States.", "US and ROW.", and "International distribution to the countries of …".
- Two-letter words that are also state codes ("IN", "OR", "ME") count only in a code-list context.
- **Fixes a false-positive bug.** Country-code lists ("the countries of AE, AT, CA, DE, IN …") were being read as US states: California, Delaware, Indiana. In the live sample this affected 34 of 1,000 records.
- New `distribution_pairs()` helper, so converters write the parsed geography onto the recall node.

## Live check (1,000 newest device/recall records, api.fda.gov, last_updated 2026-09-28)

**What the records carry:**

- Firm FEI number: 1,000 / 1,000 (100%)
- FDA root cause: 1,000 / 1,000 (100%)

**What the parser found:**

| Result | Records |
|---|---|
| At least one US state | 547 |
| "Nationwide" only | 423 |
| Countries outside the US | 427 |
| Nothing parsed | 9 (99.1% parsed) |

The 9 unparsed records say "Pending" or "Refer to the attached consignee list". Those are true unknowns.

**Transform and validation:**

- 48,248 triples.
- Parses as Turtle.
- Conforms to `identity.shacl.ttl` and `postmarket.shacl.ttl` (pyshacl).

    python pipeline/run.py --sources recalls,recall_db --stage all --shapes ontology/shapes
